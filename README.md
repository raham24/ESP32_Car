## ESP32 based RC car

This is a random project I started with some leftover hardware I had lying around. A few key features I am planning on implementing are as follows

- An HTTP server running on ESP32 for communication over local wifi network
- Companion application for controlling the robot (framework undecided)
- A camera for cockpit view with live stream to the application
- A custom designed 3D printed shell for the actual car printed in PLA and TPU
- Full offroad style suspension system
